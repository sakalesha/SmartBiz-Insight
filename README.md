# SmartBiz-Insight

MERN Stack Application for Business Analytics.

## Project Structure
- `frontend`: Vite + React + Tailwind CSS
- `backend`: Node.js + Express + MongoDB

## Setup
1. Backend:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
2. Frontend:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
